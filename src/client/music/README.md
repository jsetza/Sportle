# Supplied music (licensed files only)

Put an audio file here named after a music style and that style plays it on loop instead of
the built-in synthesised loop:

- `house.mp3` (or `house.m4a`, `house.ogg`, `house.wav`) → **Music: House**
- also possible: `chill.*`, `synthwave.*`, `lofi.*`

Only add music you have the rights to publish on a public website (your own music, music made
with permission, or a track licensed for games/websites). Copies of commercial songs from
Spotify, YouTube, etc. are not allowed here. Keep files under ~20 MB.
